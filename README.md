# Bar Escolar - Avance de Proyecto

Este repositorio contiene el avance del proyecto Bar Escolar. Esta versión demuestra las funcionalidades principales implementadas hasta la fecha.

## Funcionalidades Incluidas (Avance)

- **Autenticación (Login/Registro):** Sistema funcional de usuarios (Estudiantes).
- **Catálogo de Productos:** Visualización de productos disponibles con sus precios e imágenes.
- **Carrito de Compras:** Gestión de productos seleccionados para compra.
- **Procesamiento de Pedidos:** Envío de pedidos a la base de datos.

## Limitaciones de esta Versión

- **Panel Administrativo:** No incluido en esta entrega.
- **Historial de Pedidos:** No incluido en esta entrega.
- **Pagos Reales:** Simulación de éxito.

## Instrucciones de Ejecución

### Backend
1. Navegar a la carpeta `backend`.
2. Instalar dependencias: `npm install`
3. Configurar base de datos en `.env`.
4. Ejecutar seed (opcional): `npx prisma db seed`
5. Iniciar servidor: `npm run dev`

### Frontend
1. Navegar a la carpeta `frontend`.
2. Instalar dependencias: `npm install`
3. Iniciar aplicación: `ng serve`
